# Файлы для правок контента

| Файл | Что внутри |
|------|------------|
| **CONTENT_FOR_EDIT.md** | Весь текст сайта по секциям (актуальный snapshot) |
| **LAB_TEMPLATES_SOURCE_DUMP.md** | Дамп исходных Google Sheets + live xlsx |
| CONTENT_EDIT_ME.md | Старый черновик — можно игнорить |

## Как работать
1. Открой `CONTENT_FOR_EDIT.md`.
2. Правишь текст внутри секций (`===== SECTION: ... =====`).
3. Ссылки: `⟶[url]`.
4. Напиши в чат: «внеси правки из CONTENT_FOR_EDIT.md».
